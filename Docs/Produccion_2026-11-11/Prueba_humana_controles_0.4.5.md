## 1. Menú sin ratón (SYS-070) — solo mando PlayStation
- [ ] Conecta el mando: el menú dice "Mandos: 1" y la cabecera de CONTROLES dice **MANDO PLAYSTATION**, con botones Cruz / Círculo / Cuadrado / Triángulo.
- [ ] Cruceta y palanca mueven el borde blanco por todo el menú; mantener la palanca repite.
- [ ] Cruz elige: un luchador, otra vez el mismo para cambiar de aspecto, una cancha, número de rivales.
- [ ] En un rival, ← → cambia su aspecto.
- [ ] Pestañas OPCIONES → MANDO → PANTALLA; ← → ajusta valores.
- [ ] Start inicia la partida desde cualquier punto del menú.

## 2. Ajustes de mando (SYS-026)
- [ ] Vibración: al subirla o bajarla el mando vibra un instante; al 0 % no vibra.
- [ ] Zona muerta mover: con la palanca casi suelta el luchador no se arrastra solo.
- [ ] Respuesta fina / rápida se nota al caminar despacio.

## 3. Remapeo (SYS-025)

- [ ] Start durante "pulsa…" cancela sin cambiar nada.
- [ ] RESTAURAR MANDO vuelve a los valores por defecto.

## 4. Partida con teclado + mando (SYS-022/027)
- [ ] Activa "MANDOS LOCALES", P1: TECLADO Y RATÓN, 1 rival: P2 debe ser tu mando.
- [ ] El mando controla solo a P2; el teclado solo a P1.

- [ ] Desconecta el mando (apágalo) en plena partida: pausa con "Falta mando: P2", no se puede continuar.
- [ ] Vuelve a encenderlo: recupera P2 sin perder vidas ni porcentaje; Continuar / Start reanuda.
